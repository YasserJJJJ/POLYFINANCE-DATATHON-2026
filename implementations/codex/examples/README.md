# Exécutions Bedrock enregistrées

Les rapports JSON proviennent d’appels réels au compte AWS de l’atelier
le 15 novembre 2026. Ils conservent les hypothèses, calculs, sources, traces,
identifiants des requêtes et consommations déclarées.

- `robert-bedrock.json` : réduction de TSLA.
- `amira-bedrock.json` : réduction de NVDA.
- `mateo-bedrock.json` : retrait de l’exposition directe à XOM.
- `incident-mateo.json` : premier essai depuis l’interface, conclusion rejetée,
  calcul local conservé.
- `mateo-corrige.json` : validation après séparation des outils et de la
  restitution structurée.

Ce sont des preuves d’exécutions passées. Leur ouverture ne lance pas une
nouvelle inférence. Les scénarios sont entièrement fictifs. La revue et les
mesures se trouvent dans [la revue de l’agent](../docs/agent-review.md).
