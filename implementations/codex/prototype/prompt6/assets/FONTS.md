# Polices du prototype AlphaForge

Les polices sont servies localement. Aucune requête Google Fonts ne part lors de l’ouverture du prototype.

| Fichiers | Famille | Version lue dans le binaire | Usage |
|---|---|---|---|
| font-0.ttf à font-3.ttf | DM Sans | 4.004 ; gftools 0.9.30 | Texte, contrôles, chiffres ; graisses 400/500/600/700 |
| font-4.ttf et font-5.ttf | Newsreader | 1.003 | Titres ; graisses 400/500 |

Source de téléchargement déclarée par l’intégrateur, puis requête CSS relue le 15 novembre 2026 :
[https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600;700&family=Newsreader:opsz,wght@6..72,400;6..72,500&display=swap](https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600;700&family=Newsreader:opsz,wght@6..72,400;6..72,500&display=swap)

Agent utilisateur du téléchargement : `Mozilla/5.0`. Les liens des fichiers et leurs empreintes locales figurent dans [font-provenance.json](font-provenance.json). Les fichiers n’ont pas été redessinés ou modifiés ; `fonts.css` remplace uniquement les adresses distantes par des adresses locales.
