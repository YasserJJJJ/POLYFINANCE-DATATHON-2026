Mise en place
Travaillez localement, sauf si vous avez une raison de faire autrement. Votre démo est plus ﬁable quand elle tourne sur une machine que vous contrôlez, sur un réseau que vous
avez testé. Si vous développez dans le nuage, gardez une copie de votre code dans GitHub : le compte AWS et tout ce qu'il contient sont détruits le lundi 16 novembre à 13 h 59.
python3 -m venv .venv
source .venv/bin/activate          # Windows : .venv\Scripts\activate
pip install boto3 streamlit strands-agents yfinance
export AWS_REGION=us-east-1
aws sts get-caller-identity        # vérifie que vos identifiants fonctionnent
