Data Automation
Amazon Bedrock Data Automation (BDA) transforme du contenu non structuré (documents, images, audio, vidéo) en JSON structuré que vous pouvez interroger,
joindre à d'autres données et afficher dans un tableau de bord. Une seule API couvre les quatre modalités.
Pour ce déﬁ, beaucoup de données utiles arrivent dans le mauvais format : rapports annuels et communiqués de résultats en PDF, tableaux ﬁnanciers numérisés,
webdiffusions de résultats. BDA vous aide à en extraire des chiffres exploitables.
Si vous voulez simplement interroger un PDF ou en extraire quelques chiffres, vous n'avez pas besoin de BDA. L'API Converse accepte un document directement
dans le message (jusqu'à cinq documents de 4,5 Mo chacun par requête) :
Le name du document accepte seulement des lettres, des chiffres, des espaces, des tirets, des parenthèses et des crochets. Lors de nos tests sur le même PDF, Nova
2 Lite a utilisé environ 2 200 tokens d'entrée et un modèle Claude environ 21 600 : comparez le coût avant de traiter beaucoup de documents.
Passez à BDA quand vous avez du volume, des PDF numérisés, plusieurs modalités, ou besoin d'un schéma JSON ﬁxe en sortie.
La sortie standard ne demande aucune conﬁguration. Vous donnez un ﬁchier, et BDA renvoie les informations habituelles pour cette modalité : texte dans l'ordre de
lecture et résumés pour les documents, légendes, texte et logos détectés pour les images, découpage en chapitres et transcription pour la vidéo, transcription avec
identiﬁcation des intervenants pour l'audio.
La sortie personnalisée utilise un blueprint : vous déclarez les champs voulus et leur type, en langage courant ou avec un éditeur de schéma, et BDA renvoie
exactement ce JSON. C'est ce qu'il vous faut quand la sortie alimente une application plutôt qu'un lecteur humain.
BDA est asynchrone : vous lancez une tâche, puis vous interrogez son statut. Trois paramètres sont obligatoires, et le troisième est celui que tout le monde oublie.
La commande renvoie un invocationArn. Interrogez-le :
Quand le statut vaut Success, le JSON se trouve dans votre bucket de sortie :
Les blueprints sont beaucoup plus simples à construire dans la console : vous pouvez itérer sur un ﬁchier d'exemple et voir le JSON extrait immédiatement. Allez
dans Amazon Bedrock → Data Automation 
, créez un projet et ajoutez un blueprint qui décrit vos champs.
Pour un rapport annuel ou un communiqué de résultats, un blueprint utile demande par exemple :
emetteur
texte
Nom de l'entreprise émettrice
symbole
texte
Symbole boursier, s'il est mentionné
fin_exercice
date
Date de ﬁn de l'exercice ou du trimestre
devise
texte
Devise de présentation (CAD, USD)
revenus
nombre
Revenus totaux de la période
benefice_net
nombre
Bénéﬁce net attribuable aux actionnaires
bpa_dilue
nombre
Bénéﬁce par action dilué
dividende_par_action
nombre
Dividende déclaré par action ordinaire
provisions_pertes_credit
nombre
Dotation à la provision pour pertes de crédit (banques)
ratio_cet1
nombre
Ratio des fonds propres de catégorie 1 sous forme d'actions ordinaires (banques)
Une fois le projet créé, passez-le dans l'appel :
Extraction de résultats ﬁnanciers. Transformez les rapports annuels et communiqués de résultats de plusieurs entreprises en un tableau (revenus, bénéﬁce net,
BPA, dividendes), puis chargez-le dans pandas ou Amazon Athena pour comparer les émetteurs.
Documents numérisés. Les anciens rapports ou certains documents réglementaires n'ont pas de couche texte. BDA les rend lisibles avant de les indexer dans une
base de connaissances.
Webdiffusions de résultats. Transcription avec identiﬁcation des intervenants, puis un appel de modèle pour extraire les thèmes, les prévisions de la direction et les
risques mentionnés. Respectez les conditions d'utilisation de la source.
Graphiques et tableaux en image. La sortie standard des images détecte le texte : utile pour récupérer les valeurs d'un tableau publié sous forme d'image.
Documents jusqu'à 1 500 pages et 500 Mo par requête, images jusqu'à 4K et 5 Mo, vidéos jusqu'à quatre heures et 2 Go. Les formats pris en charge incluent PDF, PNG,
JPG et TIFF pour les documents et images, et MOV et MKV pour la vidéo.
Pour une démonstration, gardez des ﬁchiers petits. Un PDF de 400 pages est lent et ne prouve rien de plus qu'un extrait de 4 pages.
Supprimez aussi les projets créés dans la console. Les comptes AWS sont fermés et toutes les données détruites le lundi 16 novembre à 13 h 59 : exportez avant
cette heure ce que vous voulez garder. Voir Nettoyage et exportation.

Pour un seul PDF : lire le document avec Converse
import boto3
client = boto3.client("bedrock-runtime", region_name="us-east-1")
with open("rapport-annuel.pdf", "rb") as f:
    pdf_bytes = f.read()
response = client.converse(
    modelId="global.amazon.nova-2-lite-v1:0",
    messages=[{
        "role": "user",
        "content": [
            {"document": {"format": "pdf", "name": "rapport-annuel", "source": {"bytes": pdf_bytes}}},
            {"text": "Donnez le bénéfice net et le bénéfice par action dilué de l'exercice, avec le numéro de page où vous les avez trouvés.
        ],
    }],
    inferenceConfig={"maxTokens": 800},
)
blocks = response["output"]["message"]["content"]
print("".join(b["text"] for b in blocks if "text" in b))
print(response["usage"])

Lancer une tâche
ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
BUCKET="datathon-bda-${ACCOUNT_ID}"
aws bedrock-data-automation-runtime invoke-data-automation-async \
  --region us-east-1 \
  --input-configuration "{\"s3Uri\":\"s3://${BUCKET}/input/rapport-annuel.pdf\"}" \
  --output-configuration "{\"s3Uri\":\"s3://${BUCKET}/output/\"}" \
  --data-automation-profile-arn "arn:aws:bedrock:us-east-1:${ACCOUNT_ID}:data-automation-profile/us.data-automation-v1"

En Python, avec attente du résultat
import time
import boto3
REGION = "us-east-1"
account_id = boto3.client("sts", region_name=REGION).get_caller_identity()["Account"]
bucket = f"datathon-bda-{account_id}"
bda = boto3.client("bedrock-data-automation-runtime", region_name=REGION)
job = bda.invoke_data_automation_async(
    inputConfiguration={"s3Uri": f"s3://{bucket}/input/rapport-annuel.pdf"},
    outputConfiguration={"s3Uri": f"s3://{bucket}/output/"},
    dataAutomationProfileArn=(
        f"arn:aws:bedrock:{REGION}:{account_id}:data-automation-profile/us.data-automation-v1"
    ),
)
invocation_arn = job["invocationArn"]
print("Tâche lancée :", invocation_arn)
while True:
    status = bda.get_data_automation_status(invocationArn=invocation_arn)
    state = status["status"]
    print("statut :", state)
    if state in ("Success", "ServiceError", "ClientError"):
        break
    time.sleep(5)
print(status)
