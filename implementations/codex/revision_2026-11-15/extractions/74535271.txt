Nettoyage et exportation
La meilleure version de cette page est celle dont vous n'avez jamais besoin, parce que vous poussez votre code dans le dépôt GitHub de votre équipe depuis le début.
C'est aussi un livrable : le dépôt de code doit être remis le dimanche 15 novembre à 23 h 59.
Ensuite, faites des commits au fur et à mesure. Cinq minutes de conﬁguration le samedi éliminent le risque du dimanche soir.
S'il n'est pas dans Git, mettez-le dans Git maintenant. Si GitHub n'est pas possible, téléchargez-le :
Dans JupyterLab (SageMaker Uniﬁed Studio), faites un clic droit sur un ﬁchier ou un dossier de l'explorateur et choisissez Download. Un terminal JupyterLab permet
aussi d'utiliser git directement.
Dans CloudShell, les ﬁchiers arrivent dans votre répertoire personnel CloudShell : utilisez Actions → Download ﬁle pour les récupérer sur votre ordinateur. Pour de
gros volumes, aws s3 sync depuis votre propre machine est plus rapide.
Ne publiez pas dans un dépôt public des données dont la licence ne permet pas la redistribution : publiez plutôt le script qui les télécharge. Voir Données ﬁnancières
publiques.
Vos prompts et votre conﬁguration sont le fruit de votre travail. Enregistrez-les sous forme de texte dans votre dépôt.
Faites un commit de ces ﬁchiers. Recréer un garde-fou à partir de son JSON prend quelques minutes ; le recréer de mémoire prend un après-midi.
Faciles à oublier et pénibles à perdre. Chaque prompt système, description d'outil et exemple que vous avez ajusté doit être dans un ﬁchier de votre dépôt, pas
seulement dans un script en cours d'exécution ou un formulaire de la console.
Une page dans le README de votre dépôt : les services utilisés, le parcours des données, les sources et leurs licences, les hypothèses, les limites et la suite. Elle vous
servira aussi pour la documentation technique, un des livrables du Datathon, et elle prend quinze minutes pendant que tout est encore frais.
Tant que votre compte existe, ce qui reste allumé est facturé à l'événement. Arrêtez-le quand vous avez terminé.
Vériﬁez ensuite qu'il ne reste pas de collection OpenSearch Serverless 
 si l'assistant de création de la base de connaissances a créé un stockage vectoriel pour
vous. C'est la ressource la plus susceptible de continuer à coûter quand vous pensez avoir ﬁni.
Arrêtez aussi vos espaces JupyterLab dans SageMaker Uniﬁed Studio (Code spaces, menu …, Stop), et supprimez le reste de ce que vous avez créé : instances EC2,
fonctions Lambda avec URL publique, piles CloudFormation.

Nettoyage et exportation
Votre compte AWS sera supprimé déﬁnitivement le lundi 16 novembre à 13 h 59. Tout ce qu'il contient disparaît avec lui : code, données, notebooks, conﬁgurations. Aucune
récupération n'est possible. Exportez ce que vous voulez garder avant cette heure.
Faites-le dès le premier jour, pas à la fin
git init
git add .
git commit -m "Prototype fonctionnel"
git remote add origin https://github.com/VOTRE_EQUIPE/votre-projet.git
git push -u origin main
