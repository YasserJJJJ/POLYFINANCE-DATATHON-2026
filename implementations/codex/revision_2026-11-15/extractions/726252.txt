Bucket S3
Amazon S3 stocke vos données et vos ﬁchiers : séries de prix, rapports annuels pour une base de connaissances, résultats intermédiaires, exportation de votre
travail.
Toutes les commandes de cette page s'exécutent dans AWS CloudShell 
, déjà authentiﬁé dans le compte de votre équipe.
Les noms de bucket sont uniques dans tout AWS. Ces commandes ajoutent votre numéro d'équipe et l'identiﬁant de votre compte pour éviter les conﬂits :
Remplacez NN par votre numéro d'équipe. Notez le nom affiché : la variable BUCKET disparaît quand vous fermez CloudShell. Pour la redéﬁnir dans une nouvelle
session, relancez seulement la première ligne.
Les quatre paramètres doivent être à true.
La dernière commande sert à exporter votre travail avant la fermeture des comptes, le lundi 16 novembre à 13 h 59. Voir Nettoyage et exportation.
S3 n'a pas de vrais dossiers : les préﬁxes y ressemblent seulement. Une convention reste utile :
raw/ contient les données telles que téléchargées et ne change pas.
processed/ contient les données dérivées (rendements, indicateurs).
documents/ alimente une base de connaissances ou l'extraction de documents : rapports annuels, 10-K, communiqués de résultats.
Un préﬁxe par table (raw/prices_daily/, raw/fx_rates/) permet à Athena de traiter chaque préﬁxe comme une table. Athena écrit ses résultats de requête
où vous le lui indiquez : un préﬁxe séparé athena-results/ les garde à part.
La console S3 
 fait la même chose avec Create bucket. Laissez Block all public access coché et les autres paramètres par défaut. Avant de commencer, vériﬁez que
la région affichée en haut à droite est N. Virginia (us-east-1).

Depuis Python
import boto3
s3 = boto3.client("s3", region_name="us-east-1")
BUCKET = "datathon-equipe-NN-123456789012"  # le nom affiché par echo $BUCKET
s3.upload_file("prices_daily.csv", BUCKET, "raw/prices_daily/prices_daily.csv")
response = s3.list_objects_v2(Bucket=BUCKET, Prefix="raw/")
for obj in response.get("Contents", []):
    print(obj["Key"], obj["Size"])
s3.download_file(BUCKET, "raw/prices_daily/prices_daily.csv", "copie-locale.csv")
# Lire un fichier directement en mémoire, sans l'écrire sur le disque
body = s3.get_object(Bucket=BUCKET, Key="raw/prices_daily/prices_daily.csv")["Body"].read()
print(body.decode("utf-8")[:200])
