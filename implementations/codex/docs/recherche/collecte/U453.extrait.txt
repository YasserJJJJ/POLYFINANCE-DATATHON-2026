GitHub repositories and code examples

Agent Toolkit for AWS

The official toolkit for AI coding agents to build, deploy, and manage applications on AWS. Provides a managed MCP server, curated skills for common workflows, agent plugins, and rules files. Works with Kiro, Claude Code, Cursor, and Codex.

AWS Samples

Serves as a comprehensive library of production-ready code examples and solutions that show how to build applications using AWS services. The repository features vetted, practical implementations across a wide range of use cases.

AWS Docs
