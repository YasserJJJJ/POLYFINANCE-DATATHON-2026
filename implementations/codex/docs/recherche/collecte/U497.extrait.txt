 Se connecter à AWS Educate 

Vous êtes submergé par trop de choix en matière d'apprentissage dans le cloud ?

AWS Educate s’adresse à tous, quels que soient votre niveau de formation, votre expérience technique et votre parcours professionnel. Simplifiez votre transition vers le cloud computing et l’IA avec AWS Educate, votre parcours de formation gratuit et structuré vers des compétences techniques extrêmement recherchées.

 Lecture 

Apprendre et mettre en pratique en temps réel de nouvelles compétences en matière de cloud

 Stockage 
 
Initiation au stockage

Entraînez-vous à créer votre propre solution de stockage dans le cloud et à héberger un site Web statique dans le cloud AWS. Bénéficiez d’une expérience pratique avec Amazon Simple Storage Service (Amazon S3).

 Inscrivez-vous maintenant 

 Calcul 
 
Démarrage avec le calcul

Entraînez-vous à créer et à gérer votre propre instance de cloud computing dans le cloud AWS. Bénéficiez d'une expérience pratique avec Amazon Elastic Cloud Compute (Amazon EC2).

 Inscrivez-vous maintenant 

 Mise en réseau 
 
Démarrage avec la mise en réseau

Bénéficiez d’une expérience pratique avec Amazon Virtual Private Cloud (Amazon VPC) et apprenez à configurer des réseaux sécurisés.

 Inscrivez-vous maintenant 

 Bases de données 
 
Démarrage avec les bases de données

Entraînez-vous à lancer votre propre instance de base de données et à configurer une application Web pour vous y connecter dans le cloud AWS. Bénéficiez d’une expérience pratique avec Amazon Relational Database Service (Amazon RDS).

 Inscrivez-vous maintenant 

 Cloud Operations 
 
Démarrer avec les opérations dans le cloud

Bénéficiez d’une expérience pratique des services d’exploitation Amazon Cloud grâce à ce cours et à l’atelier qui l’accompagne : Démarrer avec l’estimation des coûts.

Avantages d'AWS Educate

 Un accès simple et libre 

 Contenu destiné aux débutants 

 Accéder à l'emploi 

Aucune carte de crédit requise

Dès l’âge de 13 ans, les apprenants peuvent s’inscrire à AWS Educate à l’aide d’une simple adresse e‑mail. Ils accèdent ensuite à des ateliers pratiques gratuits leur permettant d’acquérir et de mettre en application en temps réel de nouvelles compétences en matière de cloud.

Le cloud vous intéresse ?

AWS Educate propose une bibliothèque complète de formations en ligne gratuites et adaptées à votre rythme qui couvrent de nombreux sujets. Que vous préfériez apprendre en regardant des vidéos ou via la pratique, AWS Educate propose du contenu adapté à tous les profils. Vous pouvez même gagner des badges numériques à partager pour mettre en valeur vos compétences.
