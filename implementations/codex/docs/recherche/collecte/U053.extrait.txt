 What does "Restricted license - for non-production use only" mean?

 Gwyneth Butera

 November 24, 2025 15:44 
 Updated 

The message
 Restricted license - for non-production use only 
indicates that Gurobi is using a size-limited license included with the pip and conda installation of gurobipy. This license allows you to solve models with a maximum of 2000 variables and 2000 constraints (or 200 variables for models with quadratic terms). It is intended for research, development, and evaluation purposes only and is not permitted for commercial use.

If your model exceeds these size limits, this license may give the following error
 Model too large for size-limited Gurobi license 
If you already have a full license (academic, commercial or evaluation) and still see this error, Gurobi is not detecting your license file correctly. To resolve this issue, please see the article How do I resolve a "Model too large for size-limited Gurobi license" error? .
